CAI DAT API DANG KY DEMO

1. Tao database MySQL tren hosting.
2. Chay file schema.sql trong database vua tao.
3. Copy config.sample.php thanh config.php.
4. Dien thong tin host, database, user va password trong config.php.
5. Upload thu muc api/ cung cap voi index.html va assets/.

index.html se POST den api/submit-demo.php. Khong upload config.sample.php thay cho
config.php va khong dua thong tin database vao JavaScript.
